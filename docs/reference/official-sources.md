# Official Sources

Use first-party sources before live filings:

- Receita Federal.
- Simples Nacional / PGDAS-D.
- eSocial.
- DCTFWeb.
- Municipality NFS-e portal.
- Applicable legislation or official manuals.

For changing values such as due dates, INSS, IRRF, DIRPF thresholds, Simples Nacional rules, and Factor R rules, record:

- source URL or document,
- effective date,
- date last verified,
- rule summary,
- affected workflow/script.
