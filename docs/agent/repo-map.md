# Repo Map

- `.gitignore`: keeps private source evidence, secrets, and generated state out of Git.
- `README.md`: public operator overview.
- `AGENTS.md`: mandatory agent rules.
- `config/company.example.yaml`: sanitized local config template.
- `docs/agent/`: agent memory, handoffs, state, and open questions.
- `docs/instructions/`: portal and monthly workflow instructions.
- `docs/reference/`: terminology, data model, portal references, official sources.
- `docs/lessons/`: durable lessons from filings.
- `docs/templates/`: reusable private-session notes and filing templates.
- `schemas/`: lightweight JSON schema documentation for state files.
- `scripts/`: small Python CLIs; no network calls.
- `tests/`: invented fixtures and unit tests.
- `private/`: ignored local source evidence, secrets, state, and generated reports.
