# Operating Rules

- Evidence beats memory.
- Preserve each source file's original filename in inventory.
- Keep source evidence immutable after moving into `private/sources/`.
- Record corrections as new records; do not overwrite history.
- Generate instructions from structured state when possible.
- Never submit, close, issue, pay, or alter portal state without explicit human approval.
- Mark current tax rules and deadlines as `NEEDS CURRENT VERIFICATION` unless verified from current official sources.
